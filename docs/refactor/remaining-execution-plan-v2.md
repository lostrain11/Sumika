## 3. 不可改变的产品与安全规则

1. 主模型质量优先，接受较高价格，但不以最贵代表最强。角色在合格免费候选中优先选择；没有合格免费时提醒，用户可确认付费。两者按助手分别自动/手动，手动失效不静默换，默认改动不改变运行中任务。
2. 免费且确定简单的工作可直达；复杂免费也确认范围。付费规划、执行、验证、重试、咨询、附言均先有对应授权；只开工作台零调用，切回闲聊不停止已授权工作。
3. 资金分类保留官方免费、赠送、限免、已购、现金、未知。已购消耗不算免费。精确金额、有效期、共享原子预留、发送前复核不弱化；报价不等于预留，usage 估价不冒充账单，余额不证明旧请求结算。
4. 授权绑定目标/版本/用途/候选范围/文件与工具权限/上限，模型不能确认自己。明确消费上限不被“两倍且多五元”异常阈值放宽。无法承诺硬上限的 Harness 不得伪装为受控自动路径。
5. 未发送失败才可按策略再尝试；部分输出或提交未知不自动重发。取消停止新增派发，已经发送的调用按事实结算或保留预留。
6. 工作正文和角色附言独立；角色不改写正文。按需项目查询不默认读全目录，历史清屏不删库、模型上下文不依赖显示数组。最近三轮，前翻十轮，稳定游标去重。
7. A 方案保留，默认工作台；陪伴小窗/全景/全屏/透明是同一视图模式，不换房间。一个 Core，窗口关闭为隐藏，明确退出才停后台。内置浏览器是正式目标，兼容限制明示，不搬 Cookie 或静默开外窗。
8. 核心只依赖窄契约，适配器/装配负责宿主能力；不传整个 app/HostContext。PLUGIN-003 的独立安装、同份核心、能力/错误/生命周期、外部宿主、测试/版本/许可、无隐式私有数据或费用、卸载与分发十项标准均适用；manifest/RPC 桥不是独立验收。
9. 记忆本期只保留稳定身份/作用域/能力/迁移契约；不启自动抽取召回。场所分组只是模拟，合窗不共享私聊/记忆，真实多人另做。角色人格和世界书也不能成为授权来源。
10. Codex 个人文件不改，不移植 `cost-routing`。三 Skill 默认关闭，工具路径由独立标准库脚本处理，官方空配置、本地更新保留；不添专用路径设置页/DB/推荐服务。第三方保留作者/版本/许可，安装、用途开关、权限分别控制。
11. 高频维护优先确定性脚本，必要语义仅合格免费模型；广泛福利发现不限登录站点，线索不是领取/消费授权。新日程零付费默认，持续授权不从一次性任务扩张。

验收：临时 Git 的四种状态、复制中源修改、容量边界、IO失败；原目录 bytes/index/status 不变，清单可解释。缺少必需大文件时明确不可执行，不静默改用源目录。

**R01b 路径与文件操作边界。** 输入为冻结规格和相对路径；输出为已校验的操作或结构化拒绝。

1. 统一校验读/写/测试 cwd/diff/恢复/合入路径；源根与副本根及其父目录不能形成包含或链接回源的关系。

3. 读写采用内容 hash 前置条件、明确编码/换行、原子写入；恢复同样执行权限校验。扫描不跨配置范围链接，不能宣称已防本机任意恶意进程而无隔离支持。

验收：Windows真实临时链接、中文/空格/CRLF、越界路径、并发写入、预检后替换；无可用系统能力的场景标限制，不用跳过全部Windows用例过关。

**R01c 进程生命周期。** 输入结构化 executable/argv/cwd/env/timeout/output limits；输出有归属的 attempt、退出原因和有界日志。

1. 不拼 shell 命令，测试命令清单冻结；模型改测试脚本仍可能执行任意用户代码，必须向用户呈现本机权限事实。
2. Windows 优先受管 Job Object 或同等可验证机制，正确处理启动到登记的窗口、父退出子存活、取消/超时/输出超限/Core退出。只结束本任务拥有的进程。
3. stdout/stderr 采用有界持续读取，避免管道死锁；退出码与测试通过分别记录，截断有标记，保留用于诊断的受控日志。

验收：真实本地父子/孙进程、取消竞态、满输出、阻塞输入、Core退出；无自有孤儿且其他任务/日用进程不受影响。Job Object不是网络/文件权限沙箱。

**R01d 环境与隐私适配。** 将 Sumika 特定 PYTHONPATH、SUMIKA_DATA_DIR 移至宿主测试配置；通用执行器只接收明确环境/能力，不读取应用全局状态。环境白名单不得隐式继承凭据，工具日志、diff、异常和模型输入做同一范围审查，保留脱敏原因而不是默默删正文。

**R15a 统一入口差量。** 列每站账户读取/咨询/领取所用adapter/profile与内置支持能力；门户已嵌入不等于BrowserSkill全迁。优先真实有收益站点接原生统一工作台，登录恢复/人工接管状态清楚，后台开页不抢焦点。现有多Profile不静默合并或搬Cookie，SSO只放行明确受支持流程；兼容外窗须明确说明并沿用用户授权，不偷偷弹出。

**R15b 广泛线索与订阅。** 复用现有来源库，RSS/官方公告/公共资讯/社区线索跨未注册站收集→规范URL/来源时间→去重→官方条款核验→资格/地区/截止/资金类型→用户下一动作。源故障隔离、限速/退避、HTML/XML/链接不可信输入处理；配置fetch限制，拒绝外部feed把服务引向未授权本机/内网资源。内容不是系统指令，不能从文章文本取得消费/下载执行权限。

可选RSS输出默认仅本地或受控订阅，包含公开权益摘要和来源，不包含账号余额、Cookie、令牌或内网路径；不自动发布公网。不为去重/抓取固定调用模型，只有必要语义且合格免费才使用。没有新的合格线索也是真实结果，不能编活动补数量。

**R15c 逐站领取。** 每adapter声明read/check/claim/verify、账户关联、授权动作范围、日历/时区、幂等键、提交已知/未知及到账证据。目前魔搭已有，新增按真实可行站点逐一。点击成功不是到账；未知只读查/接管，不重发；遇付费、身份认证/OTP、条款变化停相关步骤，其他站继续。领取所得不能自动提升模型质量资格或付费授权。

验收：新增可用公开来源、故障/重复feed/过期活动、不可信链接、敏感内容不输出、一个有价值可行站点的离线与真实零费闭环；没有可行站保留原因，不把受阻站算覆盖。保留Web免费直发/付费先确认/未知不重发，24小时维护回收与单写租约证据，完全退出零联网。所有站点自动适配是持续扩展，不阻首次自改。
