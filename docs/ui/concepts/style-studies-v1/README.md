## 查看与选择

从仓库根运行：

```powershell
node docs/ui/concepts/style-studies-v1/serve.mjs
```

默认监听 `http://127.0.0.1:8877`；端口被占用时选择空闲端口并打印实际 URL。无需启动 Core、
DSH 或 Tauri。复用已安装的前端依赖；服务只提供当前设计目录、必要依赖和指定示例模型。

- `/`：实际页面预览，顶部评审栏切换五套方案。
- `/?study=e&page=capabilities`：直接打开指定方案的能力页。
- `/?study=b&view=pet`：桌宠预览，悬停或键盘聚焦显示控制。
- `/board.html?study=a`：单套三视图设计板，`study` 可选 `a` 到 `e`。
- `/board.html?overview=1`：五套总览，点击任一方案打开对应设计板。
- `raw=1`：隐藏评审栏，以浏览器视口尺寸渲染，用于验收截图。

## 五种相处方式

| 方案 | 主要区别 | 优势 | 取舍 |
| --- | --- | --- | --- |
| A 和风留白 | 顶部文字导航、格栅窗、右侧聊天、横排能力卡片 | 安静直观，适合长期默认界面 | 情绪表达较克制 |
| B 动画对白 | 全景角色、底部对白与输入、历史按需展开 | 沉浸与角色交流优先 | 长对话需要展开历史 |
| C 清透轻机能 | 左侧文字导航、侧前书桌视角、能力分类侧栏 | 操作路径稳定，配置状态清楚 | 功能感更强 |
| D 生活手帐 | 顶部页签、左页对话、右页居所、细分隔线 | 对话亲近，保留日常记录感 | 双页结构更依赖窗口宽度 |
| E 番剧日常 | 底部导航、章节标记、粉/黄/青色块、生活主舞台 | 原创二次元识别度更强 | 表达比极简方案更鲜明 |

E 的参考只限《孤独摇滚》的日常色彩节奏、MyGO 和 GBC 的生活空间与镜头感。
未使用相关作品的角色、海报、截图、Logo、音乐或同人模型；场景与图形由本项目原创。

## 共同边界

五套共用 `studies.js` 的示例角色名、会话、时间和能力状态；房间使用同一个已有 VRM、同一姿态与表情。
五个主入口为陪伴、工作台、能力、角色、设置。工作台、角色和设置本轮只展示占位入口，完整表单待选稿后深化。

能力页按「感知与交互、效率工具、生活与陪伴」分类：初始添加语音、屏幕观察、文字识别和截屏翻译，
全部保持未启用、未配置。音乐、待办和笔记只在可选库，不默认占用陪伴页。分类只是界面组织，
截屏翻译可以组合截图、翻译及可选 OCR；本轮没有新增生产能力或公共契约。

虚线加号仅向页面添加卡片，可移除与排序，重复添加被阻止。配置抽屉只展示示例状态，不启用功能、
访问设备或授予权限。移除卡片不删除数据，也不修改其他能力。聊天输入可编辑但发送按钮禁用，不伪造回复。

预览的草稿、分类和模块顺序仅保存在当前页内存；双模式互相切换时草稿保留，刷新恢复示例。
桌宠可收起输入、隐藏、显示/隐藏房间；真实 alpha PNG 不是背景色模拟。每次只存在一个 3D 视口，
按需重绘，隐藏时停止渲染。场景无自主生活、动作调度或后台服务，原生拖动、置顶、鼠标穿透及跨窗口同步未实现。

## 导出与验收

```powershell
node docs/ui/concepts/style-studies-v1/capture.mjs
```

脚本以临时本地端口启动隔离浏览器，结束后关闭浏览器与该临时服务，不停止用户预览服务。

- `exports/{a,b,c,d,e}-companion.png`：5 张陪伴页，1440×900。
- `exports/{a,b,c,d,e}-capabilities.png`：5 张能力页，1440×900。
- `exports/{a,b,c,d,e}-pet.png`：5 张桌宠，480×420。
- `exports/{a,b,c,d,e}-board.png`：5 张三视图设计板，1920×1800。
- `exports/overview.png`：五套总览，2400×2000。
- 补充：1280×800 两类客户端截图、五套透明桌宠、模块库和 390px 降级截图。
- `exports/verification.json`：最终验收记录；只有全部通过才写 `passed`，失败时保存 `failure.png`。
