# Sumika 新版总实施计划

唯一完整需求正文见 [用户批准的八阶段计划](../project/approved-plan.md)。
用户原话、来源与有效状态见 [需求原文索引](../project/requirements.json)。
实施状态与验收见 [当前进度](../project/progress.json) 和 [阶段 0/1 验收](../project/phase-01-acceptance.md)。

## 目标

基于最新已验证的 DSH，实现 Codex 日常开发替代能力；核心逻辑通过 Harness 中立接口与 DSH 解耦。

## 阶段

1. 项目与连续性基础
2. Harness 中立契约与安全边界
3. DSH 发行锁定与真实能力验收
4. Codex 日用开发平替
5. 连续性记录正式接入
6. 办公文件与桌面助手扩展
7. 角色系统基础
8. 长期角色与设备愿景

## 当前状态

- 已创建独立 orphan 分支。
- 已建立独立连续性模块、DSH 薄适配器与受管生命周期。
- 具体实现程度以项目进度记录和验收证据为准。

## 原则

- 优先复用 DSH 原生能力、社区插件和高质量开源项目。
- 新增核心逻辑保持独立，避免绑定 DSH 私有结构。
- 每个阶段记录实现、测试、真实验收、未验证内容、阻碍和回退方式。
- 项目数据备份与恢复列入计划，首版暂不考虑加密。
