# Sumika 新版总实施计划

状态：阶段 0 初始化中。

## 目标

基于最新已验证的 DSH，实现 Codex 日常开发替代能力；核心逻辑通过 Harness 中立接口与 DSH 解耦。

## 阶段

1. 项目与连续性基础
2. Harness 中立契约与安全边界
3. DSH 发行锁定与真实能力验收
4. Codex 日用开发平替
5. 连续性记录正式接入
6. 办公文件与桌面助手扩展
7. 角色系统及长期设备愿景

## 当前状态

- 已创建独立 orphan 分支。
- 尚未实现新版运行时代码。
- 下一步建立版本锁定、Harness 契约和连续性记录骨架。

## 原则

- 优先复用 DSH 原生能力、社区插件和高质量开源项目。
- 新增核心逻辑保持独立，避免绑定 DSH 私有结构。
- 每个阶段记录实现、测试、真实验收、未验证内容、阻碍和回退方式。
- 项目数据备份与恢复列入计划，首版暂不考虑加密。
