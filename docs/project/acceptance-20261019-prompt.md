# 提示词优化接入与本地实测（2026-10-19）

范围：工作台输入区提示词优化按钮、预览/确认链路、本机/隧道 OpenAI 兼容 provider、笔记本 LFM 真实改写。未启用日用配置、未自动发送、未改角色/工作模型。

## 界面

- 按钮仍在工作台输入区 `conversation.input.right`，由 `extensions/ui/sumika-workbench/lib/client.js` 注册。
- 图标改为 Lucide 风格钢笔（`M12 20h9M16.5 3.5a2.121 2.121 0 0 1 3 3L7 19l-4 1 1-4Z`），不再使用与 WorkBuddy 相同的四角星/闪光图标。
- 只有 `prompt_enhancement.enabled`、`auxiliary.enabled` 且辅助能力包含 `prompt_enhancement` 时才可点击；否则按钮禁用并提示到设置配置辅助模型。
- 点击后父页面调用 `/api/manage/auxiliary/enhance`，只返回原文、改写与差异；面板提供「确认替换草稿」「保留原文并关闭」。
- 确认时重新比对会话、草稿、附件和 occurrence 快照；任一变化即拒绝替换并保留原文。不会自动发送、不会调用工具、不会改权限或附件。
- 代码块或 diff 在服务端直接跳过；改写未通过数字/否定/预算/权限等原文保护时状态为 `rejected`，保留原文。

## 本地 provider

- 新增 `openai-compatible-local` 辅助 provider：仅允许 `http://127.0.0.1|localhost|::1`，不要求 API key，不读取环境凭据，不自动回退云端。
- 仍然拒绝明文局域网 HTTP；笔记本服务必须经 SSH 本地端口转发到 loopback。
- 设置页辅助模型 Provider 增加「本机/隧道 OpenAI 兼容」选项；角色/工作模型 provider 不受影响。

## 真实 LFM 实测

隔离设置、SSH 隧道 `18084 -> 192.168.31.227:8084`，模型 `LFM2.5-24B-A2B-Q4_K_M.gguf`：

| 输入 | 结果 | 耗时 |
|---|---|---|
| “帮我整理一下这句话：明天下午三点开会，预算不超过50元，不要改时间。” | `reported`，未改变 | 91.513 秒（冷） |
| “把登录页的说明文字写得更清楚，保留原有权限限制。” | `reported`，未改变 | 13.307 秒 |
| 含三反引号代码块 | `skipped`，未调用模型 | 0 |
| diff 文本 | `skipped`，未调用模型 | 0 |
| “嗯就是那个明天下午三点的会然后预算别超过五十块不要改时间” | `rejected`，原文保护拒绝 | 8.574 秒 |
| “帮我把登录页那段说明文字弄得更清楚一点，但是原来的权限限制得保留着，别删” | `reported`，未改变 | 9.951 秒 |

证据：`.sumika-next/acceptance-20261019/prompt/report.json`、`report-messy.json`。

结论：链路真实接通、失败关闭和原文保护生效；但 LFM 在这组样本上要么原样返回、要么被保护拒绝，**没有一条实际可用改写**，不能声称提示词优化质量已通过。冷启动 91.5 秒，热请求 8.6–13.3 秒。

## 2026-10-19 补测：Qwen2.5-7B-Instruct Q4_K_M

- 11 条同集对比，Qwen2.5-7B 产出 8 条原始改写；产品保护后 6 条实际替换、1 条原样、3 条跳过、1 条拒绝，没有不安全改写被接受。
- 冷请求 75.7 秒，热请求 4.1–12.7 秒；体积 4.7GB，Ollama 部署。
- 同时修正了原文保护：同义否定/权限表达不再被逐字误杀；指令覆盖文本直接跳过；拒绝反转仍被拒绝。
- 其他模型：Qwen3-4B-Instruct-2507 质量次一档；Gemma3-4B 出现 JSON 后退化重复；Phi-4-mini 改写弱且会改坏 diff；Bonsai-9B Q2 无法解析。
- 完整对比、证据与部署建议见 [提示词改写模型对比](acceptance-20261019-prompt-bench.md)。
- 质量优先结论：Qwen2.5-7B 只是最佳候选，**未通过质量门**；提示词优化暂不由本地模型负责，日用保持关闭。隧道/预加载保留为可选基础设施，不代表模型已验收。
