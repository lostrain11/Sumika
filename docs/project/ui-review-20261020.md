# UI 优化与接线审计（2026-10-20）

## 结论

不建议推倒重做。当前「晴日部室」的视觉语言、四个主导航和 DSH 原生工作台都应保留；这次做的是**结构修正 + 数据页卡片化 + 删掉设计稿预留**，不是换一套 UI。

## 修复

1. **窄屏 3 列错位**
   - `layout.css` 在 960px 把 `.room-wrap` 覆盖成 3 列，而房间实际只有 2 个子块，导致 698px 下聊天被挤到右侧、下方大片空白。
   - 删除该覆盖，让 `css/room.css` 的 1024px 单列规则生效。
   - 698×1095 实测：`grid=698px`、聊天在房间下方、无横向溢出。

2. **设计稿预留进入正式版**
   - 移除活动室中可见的：`视线跟随（未接入）`、`独立桌宠窗口（预留 P7）`、`全屏壁纸陪伴（预留 P7）`。
   - 能力页/设置页现有动态渲染不再显示预留占位；审计为 0 条可见“预留/未接入”。

3. **有角色卡但没 3D 模型时被名册隐藏**
   - `bind.js` 原先只收 `complete === true` 的角色，安和昴卡因缺 `model_3d` 被排除，聊天头仍停在 Sample A。
   - 改为：有 `card` 且启用即可进名册；缺 VRM 只显示“角色卡 · 立绘占位”。
   - 修复后名册 3 人，安和昴可选中，聊天头/输入框/舞台同步切换。

4. **占位立绘被桌宠脚本搬走**
   - `buildDeskpet()` 克隆 SVG 后，又把**原 SVG** 追加到桌宠，导致主持屏 `#vport` 变空。
   - 去掉这次移动，主持屏保留立绘占位，桌宠使用克隆。

5. **数据与存储页文字墙**
   - 原来一个 `.set-card` 里连续堆说明、字段、统计、按钮。
   - 改为四个 `.data-section` 卡片区块：个人数据目录 / 用量记录 / 本地模型推荐 / 行为子记忆。
   - 推荐项改为带边框的 `.data-recommendation` 行；记录层增加独立小标题；按钮归入 action row。
   - 继续使用 `tokens.css` 唯一颜色来源，没有新增导航/入口。

## 接线审计

- **35B 本机角色 provider**：原本只有后端，已补 `openai-compatible-local` + 设置页选项 + loopback 校验，角色可用。
- **角色移除**：后端有 remove/archive；UI 在既有的「角色资源 → 从名册移除并归档」，不是缺口。
- **角色模型隧道**：目前是操作系统登录任务 `Sumika-35B-Role-Tunnel`，**产品内没有角色隧道状态/启停 UI**。这是已知缺口，不影响当前使用；后续可复用辅助模型隧道样式补一个只读状态区。
- **静态 P5/P6/P7 占位**：动态渲染已不显示；本次清理了唯一可见的 P7/未接入项。其余静态占位只作为模板，不进入可见层。
- 没有发现第二个需要新建导航的功能缺口；不建议为此加平行面板。

## 边界

- 这是结构/可读性优化，不是完整视觉重做；如果你要更大幅度的视觉方向调整，建议先定一套新设计稿再动产品，避免又出现“另写一套外壳”。
- 700px 以下聊天会排在舞台下方；如果希望“聊天优先”，需要单独讨论移动端布局。

## 第二轮：所有页复查

- **模型与连接**：`工作模型/角色模型/辅助模型` 三个按钮之前没有 CSS，渲染成一行连在一起的文字；现为统一 tab 条。本机 provider 下隐藏无意义的“凭据环境变量名”。
- **数据与存储**：修复“行为子记忆”被挂载两次造成的重复；最近 7 天统计改成两张数据卡；记录层操作归入 action row；长 textarea（排除应用等）占满整行。
- **工作台**：未连接时由顶部裸错误文字改为居中空状态卡；去掉“正在连接”与错误态重叠的文字。
- **活动室**：卡-only 角色可进名册；主持屏立绘占位保留；移除 P7/未接入；698px 单列。
- **能力**：现有分组卡与右侧详情保持一致，不做无依据的卡片增高/删功能。
- **外观/通用/关于**：内容少但结构正常，未为了“看起来满”添加死控件。

证据：`.sumika-next/ui-audit-20261020/final-r34/*.png`、`audit.json`。

## 第三轮：图标与间距

- 能力页空图标根因有两类：`CAPABILITY_ICONS` 没登记真实模块 id（如 `role-resources`），以及“就绪视图”所有卡片统一使用同一个 `state-ok`，看起来既空又重复。现按模块语义映射：办公文件=文件夹、角色卡·世界书=用户组、桌宠模式=心形；浏览器=地球、定时任务=日历。
- 数据页“添加偏好或目标”和“记录层”挤在一起：给数据分区内的 h4 加分隔线和上间距，记录层操作加 action row。
- 连接与权限：排除应用 textarea 占满整行，授权按钮归入 action row。
- 模型页：三个 scope 改为 tab 条；本机 provider 隐藏凭据字段。
- 工作台未连接：居中空状态卡，加载文案不再和错误态重叠。

证据：`.sumika-next/ui-audit-20261020/polish/shelf-visible-icons.png`、`data-spacing4.png`。

## 最终整理（r54）

- 能力页状态只保留两项含义：`已启用/已停用`（绿/红）与 `可配置`（蓝）。有配置的卡片两个胶囊同时出现，状态区与左侧图标 32px 同高；单状态顶部对齐。
- DSH 原生分组标题已说明归属，卡内不再重复 DSH 原生标签/页脚；技术性依赖检查页脚已移除。
- 右侧详情：按 capability id 精确映射；Skills/MCP 打开 DSH 工作台，定时任务打开本地任务列表，角色卡提供角色列表与导入弹窗，网页咨询提供配置入口。
- 角色导入改为模态框；默认名册只保留 `sampleA` → “Sumika 示例助手”，`sumika-guide` 不再列出，安和昴只作为用户归档数据存在。
- 顶栏模型胶囊：活动室显示角色模型（优先 MiniCPM-V 4.7，位置本地/局域网/云端），工作台显示“工作模型 · DSH”，其他页面隐藏模型胶囊和本地服务状态。
- 桌宠：镜头光圈悬浮球，角色首字，漂浮/悬停/拖动/展开动画；活动室不显示桌宠，其他页面显示；收起入口在气泡标题栏右侧箭头。
- 截图：`.sumika-next/ui-audit-20261020/review2/r52-shelf.png`、`r52-room.png`、`status-chips.png`、`lens-orb.png`。

边界：r54 是便携候选；干净机安装仍以 r32 为最近通过基线，r54 未执行干净机安装。
