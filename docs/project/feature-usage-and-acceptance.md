涉及纠正、遗忘、恢复、重置、删除、迁移和归档时，先导出并使用测试角色/数据。隔离启动验收通过不代表直接双击候选会自动隔离日用数据；破坏性测试前须配置专用数据目录。模型/设备不可用与产品缺陷分开；状态未知的发送/迁移/恢复不要盲目重试。

```powershell
& 'E:/SumikaBuild/acceptance-20261017-current/candidate-rc2-r27/Sumika.exe' -Port 8766 -DataDirectory 'E:/SumikaBuild/manual-acceptance-20261019/data-r27'
```

随后在浏览器打开 `http://127.0.0.1:8766/`。该目录不带你的日用模型配置、角色或历史，按下文从设置配置，导入测试角色包。不要复制凭据文件到项目或报告。上述参数沿用现启动器与已验EXE接口；此固定端口手测命令本身未另行运行。

### B站浏览器扩展准备（T045）

1. 保持隔离Sumika运行。进入Edge `edge://extensions` 或Chrome `chrome://extensions`，开启“开发人员模式” → “加载解压缩的扩展”，选择候选目录下的 `browser-extensions/sumika-companion`。这是附带的生产扩展，不是 `tools` 下的研究原型；不需要运行Node构建。

3. 打开一个B站视频页并开始播放 → 浏览器工具栏扩展图标 → “连接本页”。回到Sumika **能力 → 语音交互 → 陪学会话** → “刷新学习窗口列表” → 选择待确认B站标签页。交流模式选择“文字”；如需视频声音转写，先勾“采集应用声音”；点击开始陪学并核对确认范围。

## 定时执行详细步骤

1. 打开工作台；在原生项目中准备一个standard主会话。创建不会调用模型，后续到期执行会使用该会话的模型和原生工具权限；角色/子Agent/归档会话不能作为目标。
2. 点击 **能力 → 定时任务卡 → 管理定时任务 → 新建任务**。填写任务内容，选择一次性/每日/每周。每日写`09:00`；每周写`0 09:00`（0周一，6周日）；一次性填写未来含偏移的ISO时间，例如`2030-01-02T09:30:00+08:00`。一次性按表达式偏移解释，时区字段用于周期规则。
3. 类型选 **执行（需要单独绑定）**，选择目标项目和目标会话；点击 **确认并创建原生任务**。确认框须显示完整任务、时间、时区及目标。先取消：不创建；再确认：只创建一个，当前创建按钮锁定。
4. 点击 **打开原生自动化任务**，应切到工作台原生同一任务页，能看见新任务；点击原生任务行查看规则、目标与投递历史，并使用原生编辑/删除。此处只有跳转按钮，不另维护一份原生任务清单。
5. 创建若显示“未确认”，先在原生页按内容和目标核对，勿另建相同任务；网络恢复不应自动补发。关闭弹窗不会取消原生已保存任务，需到原生页删除。删除不撤销已经投递到会话的消息。
6. 保持Sumika及工作台运行，到期应回原会话产生任务消息。原生历史是投递回执，不是工作完成证明；任务涉及工具时仍需相应许可/原生审批。应用关闭时不运行；重开后的过期规则由DSH原生调度解释，不承诺后台系统计划或精确实时执行。
7. 另建 **提醒**，保存本地定义后显式启用；到期只出现提醒记录，可标已读。编辑/停用/删除保留历史；旧执行定义保持blocked，不因这次升级开始运行。原生创建不应混入本地定义列表。
