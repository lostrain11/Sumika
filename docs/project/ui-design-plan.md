## 任务

1. **参考取舍**：必要时隔离预览旧版，结合当前 DSH Web，列出值得保留、应简化和需要重新设计的具体交互。
2. **信息架构**：规划日用开发入口、项目/会话导航、任务状态、能力与设置；为后续角色与内置浏览器预留一致入口，未实现功能明确标识。
3. **关键流程**：新建/继续任务、查看执行与确认/取消状态、打开能力模块、配置模型、切换新增功能开关。真实开关行为复用已有 enabled 契约，关闭保留数据。
4. **视觉与可交互原型**：提供可供用户实际查看的主界面和设置页；确定排版、颜色、密度、状态反馈及基本窗口尺寸适配。原型模拟状态明确标识，不假装后台已接通。
5. **接入清单**：逐页说明复用的 DSH 页面/接口、独立 UI 层的职责、现有接口与待补接口；区分设计完成、UI 实现、真实功能接通。
