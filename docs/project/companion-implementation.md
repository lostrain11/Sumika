# 陪学与陪伴当前实现

更新：2026-10-18。总体仍在验收中。当前隔离候选已包含单帧摄像头、资源目录导入与失败回滚；版本、证据和未完成项统一见[主线修复与验收计划](repair-and-acceptance-plan.md)。使用方法见[功能使用与验收清单](feature-usage-and-acceptance.md)。

## 产品入口与实现

唯一入口为能力 → 语音交互 → 陪学会话。沿用设计稿能力详情，不增加主导航。普通问题继续使用活动室或桌宠的原消息框。

|能力|实际实现与边界|
|---|---|
|窗口观察|选择明确窗口及进程身份后确认；独立采集进程持续提供窗口文字/图片，停止与目标变化使旧结果失效|
|B站陪学|生产浏览器扩展连接用户确认的标签页；字幕、画面、媒体时间与弹幕有来源；应用声音与麦克风问题分开|
|PDF阅读|当前页/选区采集及可靠文档身份；不可自动取选区时使用既有粘贴回退；粘贴上下文不能被下一轮同目标刷新覆盖|
|共享问答|StudySessionCoordinator组合观察、文字/语音与后台讨论；问题冻结来源，取消/换目标/停止使迟到回答失效|
|摄像头单帧|用户已批准在现有会话新增逐次确认按钮；默认摄像头单帧，独立桌面运行时15秒超时、内存JPEG限400 KB/最长边1024；预热后释放设备、不写图片文件。原消息框提问时才发送已配置角色模型；停止清除上下文。连续采集期间须先停止|
|语音|一次录音入草稿、连续麦克风提问、应用进程声音和网页音轨分别授权；取消和播放状态分别处理|
|主动讨论/弹幕/笔记|后台讨论受用户开关、预算及前台问题占用约束；弹幕摘要仅显式触发且标记为观众讨论；笔记显式保存并绑定回答时来源|
|行为子记忆|前台活动、操作片段、材料进度、解释、派生模式及声明分层存储；许可分为记录/参考/询问；纠正、删除、迁移和统计接现有设置区域|
|陪伴模式|手动模式优先，自动依据当前授权观察选择；不确定保留未知，模式不能扩大采集权限|

关键源码：`extensions/companion/`、`extensions/behavior/`、`ui/server.py`、`ui/app/companion-session.js`、`ui/app/companion-text.js`。摄像头复用`extensions/desktop/perception.py`的授权、预热与释放，`camera_frame.py`只承担独立运行时适配。相机能力、多模态输入或模式图片来源关闭时拒绝新采集；不自动下载模型或转付费服务。

## 验收与尚未完成

- 当前候选的全量、EXE、布局矩阵及其他专项证据范围见验收计划；不同候选或旧专项不互相升级验收结论。
- 摄像头的包内合成HTTP/观察链路和陪学浏览器检查已通过。r20摄像头服务真机单帧已验，前端逐次确认与实际模型完整流程仍待验。
- 真实RawInput、密码窗口排除、COM、高频输入与长时CPU、现场麦克风权限/取消、B站/PDF完整目标选择（r18实际播放、旧录音及本轮公开B站音频短测已验）、模型质量和干净机器仍按原主线继续。
- 角色卡和VRM有运行消费者；2D、角色绑定语音和scene尚仅支持资源绑定/校验/打包，不能当作渲染、音色或场景已生效。
