# 设计稿与当前实现覆盖

更新：2026-10-18。视觉基准为 `ui/prototype-d/index.html` 及同目录资源；当前实现入口为 `ui/app/index.html`、`ui/app/bind.js`、`ui/app/management.js`、`ui/app/companion-session.js`、`ui/app/pet-session.js` 和 `extensions/ui/sumika-workbench/`。逐项操作路径见[功能使用与验收清单](feature-usage-and-acceptance.md)，当前验证结果见[修复与验收计划](repair-and-acceptance-plan.md)。

## 逐屏覆盖

|屏幕|设计定位|当前实现|状态与边界|
|---|---|---|---|
|顶栏|晴日部室品牌、全局导航、模型与连接状态|品牌、版本、活动室/工作台/能力/设置导航及真实状态|四个主入口唯一；导航和状态来自当前实现|
|活动室|部员名册、角色舞台、对话区和桌宠|角色名册、独立聊天、语音输入/朗读、资源管理与桌宠|VRM、麦克风、扬声器等真实设备另行验收；不以页面夹具代替设备证据|
|工作台|项目/任务树、会话时间线、原生输入区|由受管 DSH Web 提供项目、会话、工具、Skills、MCP、审批、提问和轨迹；Sumika 提供皮肤与客户端扩展|保留 DSH 原生工作区/会话语义和全部原生能力；不另建重复项目或任务面板|
|能力|能力卡分组、状态和详情|注册能力、就绪状态、启停和实现配置|能力页是扩展管理唯一入口；DSH 原生能力不被隐藏或复制权限逻辑|
|插件市场|设计稿没有独立市场屏；属于能力页的新增状态入口|`ui/app/bind.js` 的“插件”原生卡；安装/发现页由 DSH 工作台提供|不新增顶部导航或第二套市场；Sumika 只显示精选索引状态并跳转工作台 Plugins|
|设置|设置分区、外观、模型、连接与数据|外观、模型连接、权限、行为子记忆、存储等既有分区|设置不重复提供能力页的模块清单；实际可用性以运行状态和验收证据为准|

## 已批准的扩展控件

|能力|入口与批准范围|实现边界|
|---|---|---|
|行为数据管理|设置 → 数据与存储 → 行为子记忆|统计、声明、分层记录、询问、纠正/删除、导出与迁移在同一区域；许可独立控制记录、参考与询问|
|陪学与自动模式|能力 → 语音交互 → 陪学会话|手动模式优先；自动判断只依据当前授权的识屏证据，不确定时保持未知，不扩大采集许可|
|摄像头单帧|同一陪学会话 → 摄像头采集一帧；设计稿无该控件，用户已批准|每次确认，仅默认摄像头一帧；连续采集须先停止。原消息框提问、停止陪学清除；禁用相机/多模态/模式图片来源时拒绝，不新增导航或页面|
|长期记忆治理|活动室或能力页既有角色记忆入口|共享同一角色记忆管理弹窗；按角色隔离，支持纠正、遗忘、关系管理、导出与恢复|
|角色资源|活动室 → 部员名册 → 管理角色与记忆 → 管理角色资源|背景、世界书和角色配色在原资源弹窗编辑；角色卡原始字段保留|
|定时执行|能力 → 定时任务 → 管理定时任务|本地提醒保留；执行任务显式绑定 DSH 项目/主会话，DSH 原生自动化页是唯一执行任务清单|
|任务转交|活动室角色回复下的转交按钮|仅对有证据的明确任务显示；用户选择工作区会话、加入草稿并手动发送|

## 设计偏离与保留约束

- 工作台继续使用 DSH 原生侧栏和会话渲染。原生实现没有设计稿中的项目路径/计数和任务状态文案；不通过伪造数据补齐视觉。
- 长篇 Agent 输出保持文档式排版，不强制套用短角色对话气泡。
- DSH 原生轨迹、用量、用时、系统提示词、模型选择、权限模式、复制/反馈、归档和侧栏折叠均保留。
- 新能力优先放入既有页面和弹窗。界面新增须先定位设计稿、检查入口唯一性并记录覆盖，不以原型代码直接替代产品实现。
- 提示词优化按钮已改为钢笔图标并接通预览/确认；本地候选未通过质量门，暂不由本地模型负责，控件保持关闭。
- SSH 隧道字段并入既有「辅助模型」面板，不新增导航入口；状态/启动/停止按钮复用现有设置行与操作区样式。真实按钮流程与 keep-alive 未完成，日用未启用。P7长期角色与设备愿景暂缓。
- 源码接线、隔离候选、旧版安装与真实设备/模型质量分别验收；一项证据不替代其他范围。
