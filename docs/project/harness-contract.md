# 阶段 1：Harness 中立契约

`sumika_next.contracts` 定义实例、工作绑定、工具请求和任务状态。DSH 接入只能实现这个边界，不得把 DSH 路径、方法名或事件格式放入核心授权逻辑。

`Authority` 是进程内可信入口。只有受管实例可绑定工作；请求绑定实例、请求 ID/版本、会话和步骤。批准绑定完整动作与目标，单次消费，撤销后不可使用。未知或未核验实例不得获得执行授权。

当前阶段未暴露 HTTP 服务，也未连接真实 DSH。后续适配器必须由可信宿主调用 `approve`，不能把该方法直接暴露给普通 RPC 或模型工具。实例真实性和 OS 进程身份验证属于阶段 2 真实接入验收。

测试：`python -m unittest discover -s tests_next -v`。
