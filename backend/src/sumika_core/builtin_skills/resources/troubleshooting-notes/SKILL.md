# 故障经验积累

再次遇到问题先查项目故障记录，结合当前版本验证适用性。记录症状、已验证原因、失败方法、修复、适用版本和测试证据；猜测必须明确标注。更新同一条记录，不每次新增近似重复笔记。不为了积累经验收集凭据、整份日志或无关私人对话。简单偶发错误不强制建台账。写入仍遵守宿主文件权限。

启用仅使本功能可被选择和加载，不扩大宿主工具、文件、网络或消费授权。按当前请求需要使用；不依赖其他内置Skill同时启用。
