# 项目进度与交接

先读项目已有当前执行记录，再核对代码、工作区改动和测试证据；旧总结不覆盖新事实。需求只引用可验证的用户原话并脱敏，不猜测消息ID。复用一份简短执行记录，在目标变化、里程碑、阻碍和交接前更新。分清已实现、待验证、受阻与计划，不把子任务完成当整体完成。只在宿主已允许的项目路径保存记录；没有写权限时返回建议内容供用户保存。

启用仅使本功能可被选择和加载，不扩大宿主工具、文件、网络或消费授权。按当前请求需要使用；不依赖其他内置Skill同时启用。
